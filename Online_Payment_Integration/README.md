# Проектирование интеграции онлайн-оплаты и клиент-серверного взаимодействия (Frontend & Backend)

Практический проект по системному анализу, проектированию API-интеграций и прототипированию веб-сервисов (Школа 21).

---

## 📌 Цель проекта
Разработка технического задания и регламента интеграции платёжного шлюза для интернет-магазина: описание архитектурных слоёв (Frontend, Backend, Database, Payment API), формализация потоков данных и создание работающего веб-прототипа.

---

## Ключевые результаты и артефакты

### 1. Спецификация интеграции платёжного шлюза (ТЗ для разработки)
- Спроектирован сквозной сценарий проведения платежа: от ввода данных на клиенте до фиксации транзакции в БД и отправки уведомления покупателю.
- Описана архитектура взаимодействия компонентов:
  - **Frontend:** сбор реквизитов, клиентская валидация, перенаправление на платежную форму, отображение статусов оплаты (`Success / Fail`).
  - **Backend:** аутентификация по API-ключам, формирование запроса на создание сессии оплаты, обработка callback/вебхуков от платежной системы, обновление статуса заказа в БД.
  - **Payment Gateway:** проведение эквайринга, проверка 3D-Secure, отправка асинхронных уведомлений.
- Сформированы требования к обработке ошибок (таймауты, отказ банка, сетевые сбои) и безопасности данных.
- **Артефакт:** `payment_instruction.pdf`

### 2. Веб-прототипирование и тестирование интерфейсов
- Спроектирован и развернут адаптивный веб-сервис на базе CMS Tilda с интеграцией форм сбора заявок и базовой структуры каталога.
- Проведено тестирование пользовательского пути (UX/UI) и адаптивности на мобильных и десктопных устройствах.

### 3. AI-Assisted прототипирование сервисов (Vibe Coding / Replit)
- Сформированы контекстные промпты для LLM на генерацию структуры веб-интерфейса и бизнес-сценариев.
- Развернут рабочий интерактивный прототип сервиса в среде Replit с использованием современных UI-библиотек.

- **Системный анализ и интеграции:** REST API, Webhooks, Client-Server Architecture (Frontend / Backend), Payment Gateway Integration, Data Flow Diagrams.
- **Инструменты и платформы:** Tilda CMS, Replit, LLM / Prompt Engineering, Figma, Markdown.
