# Промпты для AI-прототипирования сервиса (Vibe Coding / Replit)

## 📌 Контекст задачи
Создание интерактивного адаптивного веб-прототипа сайта-визитки художника интерьерных картин с интеграцией современных UI-компонентов, формы сбора заявок и пользовательских сценариев заказа.

---

## Промпт для генерации в Replit / LLM

```text
Создай одностраничный сайт-визитку художника интерьерных картин. Используй React и компоненты UI из https://ui.shadcn.com/. Сайт на русском языке, полностью адаптивный (десктоп и мобильный).

Название сайта: «Екатерина Арсентьева — интерьерная живопись»

Концепция: художник пишет картины под конкретный интерьер заказчика. Сайт должен передавать спокойствие и профессионализм: много воздуха, минимализм, цвет приносят изображения работ, а не интерфейс.

Дизайн: фон тёплый беж #F0EBE3, текст тёмно-коричневый #4A443D, заголовки почти чёрные #2B2723, акцентные кнопки — заливка #2B2723 с текстом #F0EBE3, радиус скругления всех элементов 2px. Шрифты Google Fonts: заголовки — Cormorant Garamond 600, текст — Inter 400. Никаких ярких цветов и градиентов.

Структура страницы сверху вниз:
1. Hero: надзаголовок «ХУДОЖНИК ИНТЕРЬЕРНЫХ КАРТИН» (мелкий, разрядка, цвет #8F867A), заголовок «Екатерина Арсентьева», абзац «Пишу картины для современных пространств — квартир, кафе и офисов. По образованию я дизайнер интерьеров, поэтому подбираю работу не к стене, а к пространству целиком», кнопка «Заказать картину» (скролл к форме) и кнопка-контур «Смотреть работы» (скролл к галерее).
2. Секция «Картина под ваш интерьер»: три шага карточками — «Вы показываете пространство», «Я предлагаю решение», «Пишу и сопровождаю», с короткими описаниями и номерами 01/02/03.
3. Галерея: сетка 3 колонки (1 на мобильном) из 6 карточек-работ с изображениями-заглушками, названием (например «Северное утро») и подписью «Цифровой принт · печать до 120×180 см · Под заказ»; при клике изображение открывается увеличенным в модальном окне.
4. Форма заявки: поля Имя, Email (с валидацией формата), Телефон, выпадающий список «Тип запроса» (Заказать картину / Подбор под интерьер / Узнать стоимость), Комментарий; после отправки показывать сообщение «Спасибо! Отвечу в течение 1–2 дней».
5. Футер: «© Екатерина Арсентьева, 2026», email, ссылка на Telegram.

Сценарии пользователя:
(1) посетитель прокручивает сайт и по кнопке из hero попадает к форме;
(2) открывает работу в галерее и из модального окна нажимает «Заказать похожую» — попадает к форме с предвыбранным типом запроса «Заказать картину»;
(3) отправляет форму и видит подтверждение.

Без бэкенда: отправку формы имитируй сохранением в состояние и показом подтверждения.
```

## Параметры окружения
- **Стек:** React, Tailwind CSS, shadcn/ui, Google Fonts (Cormorant Garamond, Inter).
- **Среда разработки:** Replit.
- **Подход:** Vibe Coding / AI-Assisted Prototyping.
