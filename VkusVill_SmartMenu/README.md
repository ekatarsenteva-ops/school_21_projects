# Проектирование фичи «Умное меню» для мобильного приложения «ВкусВилл»

Практический сквозной проект по продуктовому анализу, декомпозиции требований и спецификации API (Школа 21).

---

## 📌 Контекст и бизнес-задача
В рамках исследования продуктовых инициатив для мобильного приложения **«ВкусВилл»** был проведен анализ гипотез роста. 

По результатам скоринга и оценки потенциала была выбрана ключевая фича — **«Умное меню»** (персонализированный подбор рациона и готовых блюд на основе предпочтений пользователя, истории покупок и ограничений по диете) с целью увеличения среднего чека и повторных заказов.

---

## Реализация и ключевые артефакты

### 1. Анализ гипотез и валидация ценности
- Проведен предварительный анализ продуктовых гипотез для ритейла и оценка бизнес-эффекта.
- Обоснована целесообразность разработки фичи «Умное меню» и сформировано верхнеуровневое видение продукта.
- **Артефакт:** `hypothesis_presentation.pdf`

### 2. User Story Mapping & Скоуп MVP
- Спроектирован пользовательский сценарий (User Journey): от настройки пищевых предпочтений до оформления заказа из меню.
- Сформированы пользовательские истории (User Stories) с критериями приёмки (Acceptance Criteria).
- Проведена декомпозиция эпиков на задачи и выделен минимально жизнеспособный продукт (MVP) для первой итерации релиза.
- **Артефакт:** `user_story_map.png`

### 3. Формирование бэклога разработки
- На основе User Story Map сформирован структурированный бэклог задач в таск-трекере.
- Определены статусы задач, жизненный цикл разработки и критерии готовности (Definition of Done).
- Настроены зависимости между задачами для команды разработки.
- **Артефакт:** `backlog_board.png`

### 4. Спецификация REST API
- Пользовательские действия транслированы в функциональные требования к бэкенду.
- Разработана спецификация REST API: методы (`GET`, `POST`, `PUT`, `DELETE`), эндпоинты, форматы входящих параметров и ответы сервера в формате JSON.
- **Артефакт:** `api_documentation.pdf`
